# 07 Unison API 接口含义文稿

逐条对齐 06 号文档；两者冲突时以 06 为准。字段与错误码以 B1 契约守门为准。
本文只写“接口在干什么、现场怎么讲”，不重复 06 号的字段表。

## 一、全局约定
- **信封含义**：无论成败，HTTP 状态码永远是 200。前端只看 `code === 200`，业务失败看 `message` 提示。
- **身份含义**：REST 走请求头 `X-Endpoint-Identifier`，SSE 走查询参数。演示级身份，用于回答“谁在提问、谁在打断”。
- **错误码含义**：200成功 / 400参数错 / 401身份失效 / 404房间不存在（防枚举）/ 409版本冲突。无 403（无角色）。
- **分页含义**：列表接口统一返回 `Page` 结构（`items`/`total`/`page`/`pageSize`）。
- **防枚举含义**：房间不存在和无权进入，统一返回 404 和同一句 "The room does not exist."，不提示“无权”。

## 二、房间与身份接口

### 2.1 POST /api/rooms · 创建房间
- **接口用途**：创建一个新房间，并把创建者设为第一个端，返回初始快照。
- **请求含义**：传一个 `displayName`（显示名）。创建者不需要再调 join 接口。
- **响应含义**：返回房间标识、创建者端标识、当前版本（初始为0）和初始快照。
- **错误码含义**：`400` 显示名缺失或超长（"Invalid display name."）。

### 2.2 POST /api/rooms/join · 加入房间
- **接口用途**：其他设备用房间号加入，换取长期端标识，并拉取完整历史。
- **请求含义**：传 `roomIdentifier` 和 `displayName`。扫码和手动输入走同一个接口。
- **响应含义**：返回端标识（重连不变）、当前版本和完整快照。
- **错误码含义**：`400` 房间号或显示名非法；`404` 房间不存在或无权进入（同一句文案）。

### 2.3 GET /api/rooms/:roomIdentifier/members · 在线成员
- **接口用途**：分页展示房间内的成员和在线状态。
- **请求含义**：传路径参数房间号和查询参数分页。
- **响应含义**：返回成员列表。**注意：离线端保留条目并标灰，不立即移除**，以支持离线补发归属。
- **错误码含义**：`401` 身份缺失或过期；`404` 房间不存在。

### 2.4 POST /api/rooms/:roomIdentifier/heartbeat · 心跳
- **接口用途**：把端标回在线，并带回当前版本，用于恢复会话。
- **请求含义**：请求体传 `endpointIdentifier`，**必须与请求头完全一致**。
- **响应含义**：返回是否接受、当前版本和实例号。
- **错误码含义**：`401` 头部缺失或与 body 不一致；`404` 房间不存在。

### 2.5 POST /api/rooms/:roomIdentifier/leave · 主动离开
- **接口用途**：用户主动退出房间，释放身份，清除在线状态。
- **请求含义**：无请求体，带端标识头即可。
- **响应含义**：返回是否离开成功。不清空房间历史。
- **错误码含义**：`401` 身份缺失或过期；`404` 房间不存在。

## 三、快照与帧接口

### 3.1 GET /api/rooms/:roomIdentifier/snapshot · 完整快照
- **接口用途**：拉取房间全部**已确认（confirm）**的正式事实，不含打字机动画。
- **请求含义**：带房间号和端标识。
- **响应含义**：返回当前版本、正式记录列表、在线成员和在途生成状态。
- **错误码含义**：`401` 身份缺失或过期；`404` 房间不存在。

### 3.2 GET /api/rooms/:roomIdentifier/frames · 按版本补拉
- **接口用途**：端离线恢复时，按版本段把落下的**确认类帧**补回来。
- **请求含义**：必须传 `fromVersion` 和 `toVersion`，以及分页参数。
- **响应含义**：返回确认帧列表（`confirm`/`interrupt`/`edit-receipt`）。**`delta` 逐字帧不补发**。
- **错误码含义**：`400` 版本区间非法；`401` 身份过期；`404` 房间不存在。

### 3.3 GET /api/rooms/:roomIdentifier/stream · SSE 帧流
- **接口用途**：唯一的下行实时广播通道（长连接）。
- **请求含义**：浏览器 EventSource 无法传 header，所以身份走查询参数 `endpointIdentifier`。
- **响应含义**：返回 `text/event-stream`，不走统一信封。包含快照、逐字、确认、打断等帧。
- **错误码含义**：身份无效时直接建连并发 `event: error` 帧然后关闭。

### 3.4 GET /api/rooms/:roomIdentifier/generation · 生成任务状态
- **接口用途**：只读窗口，看当前有没有在途的生成任务，以及由哪个实例持有。
- **请求含义**：带房间号和端标识。
- **响应含义**：返回在途生成视图，如果没有在途任务则返回 `null`。
- **错误码含义**：`401` 身份过期；`404` 房间不存在。

## 四、生成与编辑接口

### 4.1 POST /api/rooms/:roomIdentifier/questions · 提问
- **接口用途**：申请一次生成任务，服务端判重后才发起唯一一次模型调用。
- **请求含义**：传问题内容、客户端生成的幂等键 `generationIdentifier` 和基准版本 `baseVersion`。
- **响应含义**：返回是否受理。如果模型降级，返回 `200` + `fallback: true`，不报错。
- **错误码含义**：`400` 参数非法；`401` 身份过期；`404` 房间不存在；`409` 已有在途任务或重复提问（静默忽略）。

### 4.2 POST /api/rooms/:roomIdentifier/interrupt · 打断
- **接口用途**：裁定一个全房间统一的截断边界，停止打字机效果。
- **请求含义**：传要打断的 `generationIdentifier` 和 `baseVersion`。
- **响应含义**：返回统一边界 `boundary`。**打断不产生正式记录**。
- **错误码含义**：`400` 参数非法；`401` 身份过期；`404` 房间不存在；`409` 重复打断（静默忽略）。

### 4.3 POST /api/rooms/:roomIdentifier/edits · 并发共改
- **接口用途**：上报“基于哪个版本改”，由服务端用条件更新裁决，防止覆盖。
- **请求含义**：传基准版本、目标记录、修改内容、幂等键。
- **响应含义**：成功则返回新版本和新记录；失败则返回最新快照供前端回滚重放。
- **错误码含义**：`400` 参数非法；`401` 身份过期；`404` 房间不存在；`409` 版本过期（前端必须按新快照回滚）。

## 五、状态与诊断接口

### 5.1 POST /api/rooms/:roomIdentifier/echo · 往返延迟
- **接口用途**：提供服务端时间基准，用于角标计算 RTT（往返延迟）。
- **请求含义**：传一个 `clientNonce`（仅回显）。
- **响应含义**：返回服务端收到和发出的时间。**不能用端时钟排帧序**。
- **错误码含义**：`401` 身份过期；`404` 房间不存在。

### 5.2 GET /api/rooms/:roomIdentifier/status · 角标五读数
- **接口用途**：返回右下角角标的五个读数（实例、在线数、延迟、版本、滞后）。
- **请求含义**：带房间号和端标识。
- **响应含义**：全部来自服务端，不混本地估算。故障变色只由本端连接状态驱动。
- **错误码含义**：`401` 身份过期；`404` 房间不存在。

### 5.3 GET /api/health · 实例存活
- **接口用途**：公开接口，用于落地页检查服务是否可用、看流模式。
- **请求含义**：无参数。
- **响应含义**：返回实例号、健康状态、流模式、故障开关。
- **错误码含义**：无业务分支。

## 六、演示与故障接口

### 6.1 POST /api/demo/stream-mode · 运行时切流
- **接口用途**：不重启服务，在 `live` 和 `mock` 之间切换模拟流。
- **请求含义**：传 `streamMode`（`live` 或 `mock`）。
- **响应含义**：返回切换前和切换后的模式。
- **错误码含义**：`400` 模式取值非法。

### 6.2 POST /api/faults/:action · 故障注入
- **接口用途**：现场制造四种可控故障（停实例/断网/高并发/加延迟）。
- **请求含义**：路径指定动作，body 传对应参数。
- **响应含义**：返回是否生效及受影响的实例/端。
- **错误码含义**：`400` 动作非法或参数越界；`409` 动作重复注入。

## 七、SSE 帧结构（帧字段表，非信封）
- **公共字段含义**：版本号（仅展示/定序）、房间号、帧类别、时间戳、实例号。
- **七类 frameKind 载荷含义**：
  - `snapshot`：进房首帧。
  - `delta`：逐字帧，不递增版本，只写 draft。
  - `confirm`：唯一产生新版本的帧，落库。
  - `interrupt`：打断边界。
  - `edit-receipt`：编辑裁决回执。
  - `status`：每秒推一次的角标五读数。
  - `echo`：延迟探测回显。
- **传输约定含义**：合批发送、按版本排序、断线重连（Last-Event-ID）、保活注释帧不算业务。
