# 英语文案基线

规则：全仓提示语英语一致性零例外；文案冲突交 B1 裁决
风格：简洁陈述句、首字母大写、句末句号、现在时或祈使句、不用感叹号 / emoji / 缩写形式（don't 写 do not）
来源：页面三态照 05 号第四节；错误码 message 照 06 号 1.3；不自行翻译

## 一、错误码 message

| code | 含义 | 英语 message | 状态 |
|---|---|---|---|
| 200 | 成功 | "Success." | 已定 |
| 400 | 参数或业务规则不允许 | "The request parameters are invalid." | 已定 |
| 401 | 身份问题 | "The endpoint identity is missing or has expired." | 已定 |
| 404 | 资源不存在 | "The room does not exist." | 已定 |
| 409 | 版本冲突 | "The base version is stale. The latest snapshot was returned." | 已定 |

400 专用句（按场景，照 06 号 1.3）：
"Invalid room identifier." / "Invalid display name." / "The stream mode is invalid." / "The version range is invalid." / "A generation is already in progress." / "The generation was interrupted." / "The fault is already active."
